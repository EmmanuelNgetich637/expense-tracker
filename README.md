# 💸 Expense Tracker

A simple and intuitive web application to track your daily expenses. Users can add expenses, categorize them, and view them in a clean, structured table. Built with **React**, **JavaScript**, and **Tailwind CSS**.


## 🚀 Features

- 🔍 Search through added expenses
- ➕ Add a new expense with description, category, amount, and date
- 🧾 View all expenses in a table
- 🌗 Dark-themed UI with clean layout

## 🛠️ Tech Stack

- **Frontend**: React, JavaScript (ES6+), Tailwind CSS
- **Tooling**: Vite / Create React App 
- **Deployment**:  GitHub Pages
